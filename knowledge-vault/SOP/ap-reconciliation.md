# AP Reconciliation

ขั้นตอนตรวจเจ้าหนี้กับ GL

1. เลือกบริษัทและช่วงวันที่
2. ตรวจยอดยกมา
3. รวมเดบิตและเครดิตของบัญชีเจ้าหนี้
4. เทียบเอกสาร AP กับรายการ GL
5. ตรวจเอกสารกลับรายการและเอกสารที่ไม่มี reference
6. สรุป warning ก่อนส่งต่อให้ผู้จัดการ
